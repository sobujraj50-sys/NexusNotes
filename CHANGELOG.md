# Changelog

## 1.0.0-rc1 — Milestone 10
- Release builds optimised with R8 (smaller APK, faster screens); crash reports stay readable.
- Database health check (Backup & Restore › Maintenance).
- Vault auto-lock no longer reads a file on the main thread.
- Large-note performance tests; security review; full release test plan; signing fingerprint documented.

## 0.9.0 — Milestone 9
Reminders (repeat, snooze, survive restarts), templates, home-screen widget, launcher shortcuts, automatic backups, optional offline AI tools.

## 0.8.0 — Milestone 8
Verified backups (SHA-256), Merge/Replace restore with undo, encrypted vault in backups, TXT/Markdown/JSON/PDF export.

## 0.7.0 — Milestone 7
Encrypted Private Vault (AES-256-GCM, PIN + Android Keystore, fingerprint), auto-lock, screenshot blocking.

## 0.6.0 — Milestone 6
Photo/audio/file attachments, image viewer, Share to Nexus Notes.

## 0.5.x — Milestone 5
AI Prompt Library with {{variables}}, runner, history, import/export.

## 0.4.0 — Milestone 4
Offline full-text search (English and Bangla), filters, search history (opt-in).

## 0.3.0 — Milestone 3
Folders and tags.

## 0.2.0 — Milestone 2
Notes with autosave, Markdown editor, Trash, Archive.

## 0.1.0 — Milestone 1
Project foundation, navigation, theme.
